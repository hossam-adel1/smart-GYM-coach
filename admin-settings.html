Prototype limitations

Understand what these settings do and do not control.

Client-side role checks are not secure authorization. A user can edit browser storage or JavaScript. A production application must validate administrator permissions on a trusted server.
  • Local persistence
    Settings can be saved to this browser's smartGym_settings key.
  • Cross-page integration
    Other HTML pages must explicitly read the documented settings structure to use these values. Saving here does not automatically change their calculations.
  • Other users and devices
    Local changes do not update other users' browsers or synchronize between devices.
  • Demo data export
    Export creates a JSON download of readable localStorage entries. It does not upload the data anywhere.
